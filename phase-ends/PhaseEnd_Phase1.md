## Build Log

**Files created and complete — do not recreate:**

- `StiltzkinsBag.Core/Models/Settings.cs` — All user feature toggles, RandomizerMode and EquipmentMode enums, seed string + resolved int, game path. System.Text.Json serialization (ToJson/FromJson). ToSettingsString/FromSettingsString stubbed with NotImplementedException for Phase 7.
- `StiltzkinsBag.Core/Models/GenerationResult.cs` — Pipeline run output carrier. Static factory methods Succeeded(outputPath) and Failed(errors). Init-only properties. Consumed by MainViewModel in Phase 7.
- `StiltzkinsBag.Core/Models/ItemRemapTable.cs` — Maps original item IDs to shuffled replacements. Passthrough() factory returns identity table so binary editors always call Remap() unconditionally without checking a flag. Immutable after construction.
- `StiltzkinsBag.Core/Randomizers/SeedEngine.cs` — Converts user seed string to deterministic int via djb2-style polynomial hash. Platform-independent — does not use string.GetHashCode(). CreateRandom() returns the single seeded Random instance for the pipeline. Consumed by RandomizerEngine in Phase 5+.
- `StiltzkinsBag.App/App.xaml` — MaterialDesign resource bootstrap. Merge order: BundledTheme → MaterialDesign2.Defaults → FF9Palette overrides. StartupUri points to Views/MainWindow.xaml.
- `StiltzkinsBag.App/App.xaml.cs` — Minimal Application subclass. Namespace StiltzkinsBag.App.
- `StiltzkinsBag.App/Views/MainWindow.xaml` — Shell window. Three-row layout: header (title + subtitle), content area (placeholder), footer (seed field + Random Seed button + Generate button). All interactive controls disabled pending Phase 7.
- `StiltzkinsBag.App/Views/MainWindow.xaml.cs` — Codebehind for MainWindow. InitializeComponent only. Namespace StiltzkinsBag.App.Views.
- `StiltzkinsBag.App/Resources/Themes/FF9Palette.xaml` — Stiltzkin color token resource dictionary. Defines SB.Primary, SB.Accent, SB.Background, SB.Surface, SB.SurfaceRaised, SB.TextPrimary, SB.TextSecondary, SB.TextDisabled as both Color and SolidColorBrush keys. Consumed by all XAML files going forward.
- `StiltzkinsBag.Tests/SeedEngineTests.cs` — 7 unit tests covering: same string → same int, different strings → different ints, always non-negative, whitespace trimming, empty/whitespace → 0, same int → same RNG sequence, string overload matches int overload.

**NuGet packages installed:**
- `StiltzkinsBag.Core` — CsvHelper
- `StiltzkinsBag.App` — MaterialDesignThemes, MaterialDesignColors
- `StiltzkinsBag.Tests` — xUnit, xunit.runner.visualstudio, Microsoft.NET.Test.Sdk (via xUnit project template)

**Test results:** 7/7 StiltzkinsBag.Tests passing.

**Milestone achieved:** App launches. WPF shell renders with FF9 dark theme, gold header, and disabled footer controls. Solution compiles clean across all three projects.

**Next:** Phase 2 — CSV I/O Layer. Start with `CsvParser.cs` and the first typed CSV model classes.
